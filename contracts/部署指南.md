# 部署指南（发给执行部署的人）

> 目标：把 4 个合约部署到区块链上并接好线。全程只需运行 3 条命令，脚本会自动校验。
> **强烈建议先在测试网做一遍**（免费），确认无误后再上主网。

---

## 一、你需要准备

| 项目 | 说明 |
|------|------|
| 一个**专门的干净钱包** | 只用来付 gas。**不要用日常钱包**，私钥只放在本机 `.env` 文件里 |
| gas 币 | 钱包里要有目标链的原生币（测试网先去水龙头领免费的） |
| RPC 地址 | 目标链的 RPC URL（向项目方要，或从链的官方文档拿） |
| 收款地址 TREASURY | **向项目方要**（这是收每笔 mint 30% 的地址） |
| owner 地址 | 可选。默认 = 部署钱包；一般填项目方的地址 |

---

## 二、部署步骤

### 第 1 步：装 Foundry（只需一次）

Windows（Git Bash 或 WSL）、Mac、Linux 通用：

```bash
curl -L https://foundry.paradigm.xyz | bash
foundryup
```

装完执行 `forge --version` 有输出就成功了。

### 第 2 步：进入项目目录

把整个 `contracts` 文件夹拷到本机，进入目录：

```bash
cd contracts
```

如果 `lib/` 文件夹是空的，先装依赖：

```bash
forge install foundry-rs/forge-std
forge install OpenZeppelin/openzeppelin-contracts
```

### 第 3 步：填配置

```bash
cp .env.example .env
```

用记事本打开 `.env`，至少填这三项：

```
PRIVATE_KEY=0x你的部署钱包私钥
RPC_URL=目标链的RPC地址
TREASURY=项目方的收款地址
```

其余参数（难度、价格、总量等）已经按定稿填好，**不要改**。

### 第 4 步：先"空跑"一遍（不发真实交易，不花 gas）

```bash
forge script script/Deploy.s.sol --rpc-url $RPC_URL
```

输出里会显示全部配置和预估 gas。**仔细核对配置**（特别是 treasury 地址），没问题再进下一步。

### 第 5 步：正式部署（花 gas）

```bash
forge script script/Deploy.s.sol --rpc-url $RPC_URL --broadcast
```

成功后会打印 4 个合约地址：

```
CardNFT : 0x...
Rewards : 0x...
Vault   : 0x...
Mine    : 0x...
```

**把这 4 个地址完整发给项目方。** 脚本最后会自动校验接线，如果出现 `WIRING FAIL` 或 `OWNER FAIL`，**停下来**，把完整输出发给项目方，不要继续。

### 第 6 步：验证源码（推荐）

在区块浏览器上公开合约源码，玩家才能自己检查代码、建立信任。多数 Etherscan 系浏览器支持：

```bash
forge verify-contract <合约地址> src/CardNFT.sol:CardNFT --rpc-url $RPC_URL --verifier-url <浏览器API> --etherscan-api-key <KEY>
```

4 个合约都要验证（把文件名换成 `src/Rewards.sol:Rewards` 等）。如果该链不支持自动验证，就在浏览器上手动上传 `src/` 里的源码。

## 三、防坑清单

1. **私钥安全**：`.env` 绝不能提交 git、不能发到群里。部署完成后可以把钱包余额转走。
2. **地址先核对**：TREASURY 填错 = 30% 收入进别人口袋（虽然 owner 之后可以用 `setTreasury` 改，但已经进错地址的钱拿不回来）。部署前**和项目方当面核对一遍地址**。
3. **先测试网**：测试网部署免费，随便试。测试网玩通了再上主网。
4. **部署不可逆**：合约上链后永久存在，参数（难度/价格/总量）写死不可改。部署就是"一锤子买卖"，配置核对要慢。
5. **gas 不够**：报 `insufficient funds` 就是钱包 gas 币不足。
6. **交易卡住**：RPC 慢或 gas 给低了，换 RPC 或重发。

---

## 四、部署完成后

1. 把 4 个合约地址发给项目方
2. 把 `broadcast/` 目录里的部署记录也保留一份（里面有每笔部署交易的哈希，方便查证）
3. 等下一步：图片上传 IPFS → 设置 baseURI → 矿机和前端填入地址 → 开玩
