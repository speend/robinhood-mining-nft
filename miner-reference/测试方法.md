# 怎么验证矿机真的能挖（不花一分钱）

核心思路：**在本地链上用低难度快速挖**，几秒钟就能挖到一个码，然后用合约免费校验 + 真 mint 一张卡。整套流程零成本、可反复跑。

## 第 1 步：起本地链

```bash
anvil --port 8545
```

## 第 2 步：部署合约（故意把难度调到 8 bits，秒挖）

```bash
cd contracts
PRIVATE_KEY=0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80 \
TREASURY=0x70997970C51812dc3A010C7d01b50e0d17dc79C8 \
START_PRICE_WEI=250000000000000 \
BASE_BITS=8 \
forge script script/Deploy.s.sol --rpc-url http://127.0.0.1:8545 --broadcast
```

记下输出的 Mine 和 CardNFT 地址。

## 第 3 步：跑挖矿页

```bash
node server.js     # 在交接包目录里
```

浏览器打开 `http://127.0.0.1:8788/`，地址填 anvil 第一个账户：
`0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266`，难度填 `8`，点开始。

几秒内应挖出 nonce（页面会显示 nonce、hash、算力）。

## 第 4 步：用合约验证这个码（关键！）

```bash
cast call <Mine地址> "isValidNonce(address,uint64,uint256)(bool)" \
  0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266 <挖到的nonce> 8 \
  --rpc-url http://127.0.0.1:8545
```

**必须返回 `true`。返回 `false` 就是字节序错了**（见坑清单第 1 条）。

## 第 5 步：真 mint 一张卡

```bash
cast send <Mine地址> "mint(uint64)" <挖到的nonce> \
  --value 250000000000000 \
  --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80 \
  --rpc-url http://127.0.0.1:8545

# 检查
cast call <Mine地址> "minted()(uint256)" --rpc-url http://127.0.0.1:8545        # 应为 1
cast call <CardNFT地址> "ownerOf(uint256)(address)" 1 --rpc-url http://127.0.0.1:8545  # 应为矿工地址
```

## 正式联调（测试网）

合约部署到测试网后，同样的流程，把难度换成真实值（35 bits）、地址换成测试网地址即可。矿机要从合约读真实的 `currentBits()` 和 `currentMintDue()`。
