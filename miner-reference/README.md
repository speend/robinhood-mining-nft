# BUSHU 挖矿交接包

这是矿机开发的**正确起点**——里面的 shader 已经验证过"挖出来的码合约真的认"，别从零写。

## 包内容

| 文件 | 说明 |
|------|------|
| `keccak_miner.wgsl` | **已验证的挖矿 shader**（Keccak-256，与合约格式完全对齐） |
| `grinder.html` | 参考实现：能真挖出码的最小页面（含算力显示） |
| `server.js` | 本地测试服务（开发用） |
| `格式说明.md` | 合约的验证规则、消息格式、字节序（**必读**） |
| `坑清单.md` | 最容易踩的坑（**必读**，尤其第 1 条） |
| `测试方法.md` | 怎么不花钱验证"挖到的码真的能用" |

## 10 秒上手

```bash
node server.js
```
浏览器打开 `http://127.0.0.1:8788/` → 输入地址和难度 → 开始挖矿。

## 已实测验证（2026-09-24）

- shader 自带 keccak256 自检：与以太坊官方标准值一致 ✓
- RTX 4060 + Chrome WebGPU 实测算力：**630 ~ 900 MH/s**
- 全链路：8 bits 难度挖出 nonce `230690464` → 合约 `isValidNonce` 返回 **true** → 成功 mint 出卡（70/30 分账正常执行）✓

## 本包不包含（需要继续开发）

- 钱包连接（建议 RainbowKit + wagmi）
- 从合约读当前难度/价格 + 提交 mint 交易（示例代码见 `格式说明.md`）
- 进度条、断线续挖、多张连挖
- 部署到 Vercel（网页托管）
